### Walmart Sales Analysis and 12-Week Forecasting

Developed an end-to-end **Data Science and Machine Learning project** using Walmart weekly sales data to analyze store performance, seasonal trends, outliers, missing values, and the impact of **unemployment, temperature, and Consumer Price Index (CPI)** on sales. Performed data cleaning, EDA, statistical and correlation analysis, and store-wise performance evaluation. Built a **Random Forest Regression model** with time-series features, lag variables, and rolling statistics to forecast weekly sales for **45 stores over the next 12 weeks**. The project provides actionable insights for sales planning, inventory management, promotions, and business decision-making.
